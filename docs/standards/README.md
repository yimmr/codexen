## 🎯 核心原则

1. **规约优先**：所有影响多端客户端（ChatGPT / Claude / Cursor 等）的 Schema 与数据契约变更必须先立案规范或 RFC。
2. **安全不可逾越**：安全不变量独立于业务配置，任何代码改动均不得削弱或绕过底层沙箱与凭据防护。
3. **零破坏交付**：任何新增功能必须包含完整的自动化单元测试，且必须保持全量测试套件 100% PASS。
4. **公开与私有清晰解耦**：项目流程规范、演进路线与技术规格向公共仓库公开同步；具体开发排期、任务拆解与调试细案归档于本地私有目录（`docs/plans/`），避免污染公共工程。
